# ShopEase - Bootstrap 5 E-Commerce Website

A complete responsive front-end e-commerce website using:

- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- Vanilla JavaScript
- LocalStorage for cart persistence

## Features

- Responsive navigation
- Hero section
- Product categories
- Product filtering
- Product search
- Product sorting
- Product detail modal
- Add to cart
- Increase/decrease quantity
- Remove from cart
- Cart subtotal/shipping/total calculation
- LocalStorage cart persistence
- Checkout modal and form
- Newsletter form
- Toast notifications
- Responsive mobile/tablet/desktop layout

## Run

Simply open `index.html` in a browser.

The project uses CDN links for Bootstrap, Bootstrap Icons and Google Fonts, so an internet connection is needed for those external assets.

## Important

This is a front-end demo. The checkout does not process real payments or create a real order.

For a production system, connect the JavaScript to a backend/API and payment provider.
